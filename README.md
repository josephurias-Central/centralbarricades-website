# Central Barricades Website

Official website for Central Barricades.

## About

Central Barricades provides professional traffic control services throughout Central Texas, including:

- Traffic Control Plans (TCPs)
- Lane Closures
- Flagging Operations
- Officer Protection Services
- Special Event Traffic Control
- Traffic Control Equipment Rentals
